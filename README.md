# Portfolio Philosophy

I believe cybersecurity skills are best demonstrated through **practical investigation and documented evidence**.

Rather than simply listing technologies or certifications, this portfolio is designed to show:

**What happened → What evidence was available → How I investigated it → Why I chose a particular search or technique → What I discovered → How I reached my conclusion**

This approach reflects the analytical mindset required in Security Operations and provides a record of my continued development as a SOC Analyst.
